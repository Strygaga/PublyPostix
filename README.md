\# PublyPostix



Бот для автопостинга и одновременной публикации видео и постов в соцсети из одного окна Telegram.



\## Что делает проект

Позволяет отправить медиафайл и текст в бота, после чего сценарий автоматически разносит публикацию по подключенным площадкам:

\- Telegram-каналы

\- Instagram Reels

\- ВКонтакте (Клипы / Посты)

\- YouTube Shorts



\## Стек технологий

\- \*\*Движок автоматизации:\*\* n8n (самохостинг)

\- \*\*База данных:\*\* SQLite (хранение пользователей, OAuth-токенов и логов публикаций)

\- \*\*Транспорт и API:\*\* Telegram Bot API, Meta Graph API, VK API, YouTube Data API v3



\## Текущий статус разработки

Собран рабочий прототип OAuth-авторизации и загрузки Reels в Instagram. Идет перенос состояния из памяти n8n в базу SQLite для безопасного раздельного хранения токенов пользователей.
