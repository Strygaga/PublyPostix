# PublyPostix

Бот для кросспостинга и одновременной публикации контента в соцсети из единого окна Telegram.

## Что делает проект
Позволяет отправить медиафайл и сопроводительный текст боту, после чего сценарий автоматически распределяет публикацию по подключённым площадкам:
- Telegram-каналы
- Instagram Reels
- ВКонтакте (Клипы / Посты)
- YouTube Shorts

## Стек технологий
- **Оркестрация и логика:** n8n (Self-hosted, запуск через Docker)
- **База данных:** PostgreSQL 16 (хранение пользователей, OAuth-токенов, прав доступа JSONB и логов публикаций)
- **Инфраструктура:** Docker Compose, изолированные сети, управление секретами по стандарту 12-Factor App (`.env`)
- **Транспорт и API:** Telegram Bot API, Meta Graph API, VK API, YouTube Data API v3
